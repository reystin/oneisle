# Credits and origin

## Original project

**OmniIsle** was created by **Hack337**.

- Original repository: <https://github.com/y9hack337/OmniIsle>
- Original Modrinth project: <https://modrinth.com/mod/omniisle>
- Original code base used: **OmniIsle 0.5.0** (tag `v0.5.0+mc26.2-fabric`), licensed
  **GPL-3.0-only**.

The idea of a single configurable island containing every Overworld biome, and the 0.5.0
implementation, belong to Hack337. The Git history of this repository includes the original
0.5.0 commits for traceability.

## This project

**OneIsle** is an independent continuation of OmniIsle 0.5.0. It was forked from the 0.5.0
code base in 2026, then substantially extended and finally renamed to OneIsle for its first
standalone release (1.0.0, 2026-10-29). All changes after 0.5.0 were made by **reystin**,
including:

- the 0.6.0–1.0.1 generation work inherited from the OmniIsle development line (v2/v3 terrain,
  shores, climate provinces and bands, villages, highlands, spawn selection, editor);
- the OneIsle rebrand: new mod id and namespace, Java package, class names, command,
  configuration file, share-code prefix, documentation and release pages.

Unless a file says otherwise, code and documentation added after 0.5.0 are by reystin.
