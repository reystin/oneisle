# OneIsle 1.0.0 smoke captures

Four Shape-tab captures from the post-rename in-game smoke run (`./gradlew runClient` with the
dev harness, 2026-10-29). They exist to prove the OneIsle identity loads: the editor header reads
“OneIsle” and the mod list line is `oneisle 1.0.0+mc26.3`.

- `en_1280x720_scale1_shape.png` — FULL tier, 1280×720 logical.
- `en_1280x720_scale4_shape.png` — COMPACT tier, 427×240 logical.
- `en_640x480_scale1_shape.png` — COMPACT tier, 640×480 logical.
- `en_640x480_scale2_shape.png` — MINI tier, 320×240 logical.

Only the Shape tab was captured. The full pre-rename 200-image matrix is not part of this
repository; see `docs/screens/README.md`.
