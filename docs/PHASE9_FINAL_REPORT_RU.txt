4. SHORE REDESIGN — ПОДРОБНО
--------------------------------------------------------------------------------

Проблема 0.6.0:
  - Условие shore = continentalness < 0.02 давало полосу постоянной ширины
    вдоль всего берега; полоса начиналась при c=-0.30, то есть под водой.
  - 100 % контурных точек на d≈6 имели shore biome.

Причина:
  - continentalness монотонна по расстоянию до берега; порог превращает
    расстояние в фиксированную ширину. Геометрия/шум не участвовали.

Новая модель v3:
  - patch mask: smoothstep(t0,t1, fbm(x/380,z/380,seedA)*0.65 +
    fbm(x/70,z/70,seedB)*0.35).
  - локальная ширина: lerp(3,26,noiseW)*patch; пляж при 0<=d<=w.
  - intertidal: -6<=d<0 только перед существующими пляжными карманами.
  - bayness: 8 точек кольца R=60; k=(mean(ring)-sdf(center))/R;
    bay=smoothstep(-0.15,0.25,k).
  - slope factor: крутые берега -> stony или none; пологие -> sand.
  - три исхода с jitter порогов: sand beach / stony shore / none.
  - none — самый частый исход при defaults.
  - запрещены пляжи в mushroom_fields/mangrove_swamp/swamp; badlands/desert
    могут иметь none или sand.
  - учитывается enabled_shore_biomes; пустой набор -> none.
  - ниже d<-6 всегда ocean, без покраски мелководья пляжами.

Конфигурация:
  shore: {
    "density": 0.30,
    "variety": 0.60,
    "style": "natural",
    "rocky": true
  }
  Для absence поля — legacy ribbon; v1/v2 не меняются.
  Новые миры: generation_version=3, defaults 0.30/0.60.

Редактор:
  - Beaches 0–100 %.
  - Shore variety.
  - Rocky shores checkbox.
  - Live preview: biome colors + shore overlay.
  - /omniisle debug shore: 3 цвета (sand/stony/none).
  - /omniisle debug biome: shore colors.
